# 键盘计数桌宠 

一个常驻桌面的桌宠，唯一职责是记录你**每天敲击键盘的次数**。

## 功能
- **全局键盘计数**：任你怎么在哪个软件打字都算（仅键盘，鼠标不计）。
- **每天 24:00 刷新**：前一天次数自动归档，新的一天从 0 开始。
- **历史记录**：按天存进 SQLite，可查全部历史（表格展示，最近日期排最前）。
- **各软件分布**：右键可看今天/近 7 天在哪个软件里敲得最多、待得最久（今天横向条形，近 7 天折线）。同时导出 `app_stats.json`，供 AI 直接读取分析。
- **自定义图标**：把图片放进 `assets/` 即可，重启后自动生效。
- **日程表**：点击桌宠弹出独立日程窗口（卡片+勾选+进度条），头顶角标常驻「N 待办」，临近截止半天变红。
- **点击提示**：左键单击弹出「宝宝今天点击键盘的次数是 X，快去休息吧~」。
- **一键最小化**：右键选择后，把当前所有可见窗口全部最小化（不关闭）回到桌面，桌宠仍在原位。
  - 已知限制：Windows 权限隔离（UIPI）下，无法最小化以**管理员身份运行**的窗口（如管理员终端、任务管理器），这些会被静默跳过；其它虚拟桌面上的传统程序也会被一并最小化。
- **琥珀（密码本）**：右键打开独立窗口，**输入关键词才检索**（模糊匹配名称/网址/备注）。密码经 Windows DPAPI 加密后才落库，明文只在内存短暂存在；点「显示密码」才解密，**12 秒后自动清屏**。支持新增/编辑/删除。
- **开机自启动**：右键菜单里可开/关，开机自动常驻。

## 运行
```bash
# 1. 安装依赖（Python 3.8+）
pip install -r requirements.txt

# 2. 启动
python main.py
```

## 使用
- **拖动**：按住图标拖到任意位置。
- **左键单击**：弹气泡显示今天次数，同时弹出日程窗口（待办列表）。
- **头顶角标**：常驻显示「N 待办」，有任务临近截止半天时变红。
- **右键** → 菜单：
  - 历史所有（以表格形式展示全部历史，倒序，最近的日期在最前）
  - 各软件分布（今天=横向条形 Top5，近 7 天=折线 Top3；两边都可切「次数 / 时长」）
  - 键盘热力图（26 键实时热度）
  - 一键最小化（最小化所有窗口回到桌面，不关闭）
  - 开机自启动（勾选 = 开启）
  - 退出

## 数据
数据库 `keyboard_stats.db`，表 `daily_stats`：
| date | count |
|------|-------|
| 2026-10-12 | 1234 |

按天聚合，一行代表一天。程序每天 00:00 会把当天次数写入该表并开始新 day。

### 按应用明细（daily_app_stats）
| 字段 | 类型 | 说明 |
|------|------|------|
| date | TEXT | 日期，复合主键之一 |
| app | TEXT | exe 名，如 `chrome.exe`，复合主键之一 |
| count | INTEGER | 当天在该软件里敲键次数 |
| seconds | INTEGER | 当天该软件作为前台窗口的秒数 |

只存明细（每天每应用一行），近 7 天等时间范围一律用 `GROUP BY` 现算，不建汇总表。
早期日期没有应用明细，界面显示为无数据，不回补。

### 待办日程表（todo）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| title | TEXT | 待办标题 |
| due_at | TEXT | 截止时间 'YYYY-MM-DD HH:MM'（排序键） |
| done | INTEGER | 0未完成 / 1已完成 |
| done_at | TEXT | 完成时刻（勾掉留一天用） |
| created_at | TEXT | 创建时间 |

- **勾掉留一天**：完成项当天显示，第二天自动隐藏。
- **没做轮换下一天**：未完成项自然顺延到第二天继续展示。
- **排序**：按截止时间升序（近→远）。
- **汉字展示**：`due_at` 经 `format_due()` 显示为 `2026年10月19日 14时00分`，列表第三列完整日期时间。
- **无优先级、无完成率/近7天统计**。

## 图标
桌宠自动使用 `assets/` 目录下的一张图片作为图标（优先带透明通道的 PNG）。想换图：直接替换 `assets/` 里的图片，重启程序即可生效，无需改代码、无需改配置。

## 模块结构
```
main.py          入口（含异常兜底）
autostart.py     开机自启动（启动文件夹 + VBS 静默启动器）
logger.py        运行日志（pet.log）
config.py        配置与路径（find_icon 自动扫描 assets/ 图标）
db.py            SQLite 按天聚合（含全部历史与应用明细）
db_todo.py       SQLite 待办数据层（todo 表）
db_vault.py      SQLite 琥珀数据层（vault_accounts 表，只存密文）
vault_crypto.py  琥珀加密层（Windows DPAPI，密钥不落盘）
vault_search.py  琥珀模糊匹配（归一化 + 多字段加权打分，纯函数）
listener.py      全局键盘监听
tracker.py       线程安全计数 + 跨天滚动
foreground.py    前台窗口检测（纯 ctypes，取当前 exe）
app_usage.py     按应用统计（次数 + 前台停留秒数）
app_aliases.py   exe → 友好名 + 分类（读 app_aliases.json）
stats_export.py  稳定 JSON 出口（app_stats.json）
scheduler.py     24:00 刷新 + 每 20s 落库
pet_ui/          界面包（拆分自原单文件）
  ├ app.py         PetApp 主类：窗口/图标/拖拽/菜单
  ├ renderer.py    图像流水线（Pillow）
  ├ animations.py  呼吸/挤压/拎起动画
  ├ popup.py       气泡 + MVP 徽章特效
  ├ heatmap.py     键盘热力图
  ├ app_stats.py   各软件分布（今天条形 / 近 7 天折线）
  ├ schedule.py    日程表（独立窗口 + 头顶角标）
  ├ vault_ui.py    琥珀（搜索 + 解密显示 + 自动清屏）
  ├ table.py       历史表格
  ├ minimize.py    一键最小化（EnumWindows + ShowWindowAsync）
  └ theme.py       配色与参数常量
assets/          桌宠图标（find_icon 自动发现，替换图片即换图）
```
完整说明见 `PROJECT_STRUCTURE.md`。
