# 键盘计数桌宠 

一个常驻桌面的桌宠，唯一职责是记录你**每天敲击键盘的次数**。

## 功能
- **全局键盘计数**：任你怎么在哪个软件打字都算（仅键盘，鼠标不计）。
- **每天 24:00 刷新**：前一天次数自动归档，新的一天从 0 开始。
- **历史记录**：按天存进 SQLite，可查最近 7 天 / 全部历史（表格展示）。
- **自定义图标**：图片你说了算，随时右键更换。
- **点击提示**：左键单击弹出「宝宝今天点击键盘的次数是 X，快去休息吧~」。
- **开机自启动**：右键菜单里可开/关，开机自动常驻。

## 运行
```bash
# 1. 安装依赖（Python 3.8+）
pip install -r requirements.txt

# 2. 启动
python main.py
```

## 使用
- **拖动**：按住图标拖到任意位置。
- **左键单击**：弹气泡显示今天次数。
- **右键** → 菜单：
  - 最近 7 天（以表格形式展示近 7 天）
  - 历史所有（以表格形式展示全部历史）
  - 更换图标（上传你自己的图片）
  - 开机自启动（勾选 = 开启）
  - 退出

## 数据
数据库 `keyboard_stats.db`，表 `daily_stats`：
| date | count |
|------|-------|
| 2026-10-12 | 1234 |

按天聚合，一行代表一天。程序每天 00:00 会把当天次数写入该表并开始新 day。

## 图标
桌宠自动使用 `assets/` 目录下的第一张图片作为图标。想换图：右键桌宠 → 更换图标，或直接替换 `assets/` 里的图片。

## 模块结构
```
main.py          入口（含异常兜底）
autostart.py     开机自启动（启动文件夹 + VBS 静默启动器）
logger.py        运行日志（pet.log）
config.py        配置与路径（find_icon 自动扫描 assets/ 图标）
db.py            SQLite 按天聚合（含近7天 / 全部历史查询）
listener.py      全局键盘监听
tracker.py       线程安全计数 + 跨天滚动
scheduler.py     24:00 刷新 + 每 20s 落库
pet_ui/          界面包（拆分自原单文件）
  ├ app.py         PetApp 主类：窗口/图标/拖拽/菜单
  ├ renderer.py    图像流水线（Pillow）
  ├ animations.py  呼吸/挤压/拎起动画
  ├ popup.py       气泡 + MVP 徽章特效
  ├ heatmap.py     键盘热力图
  ├ table.py       历史表格
  └ theme.py       配色与参数常量
assets/          桌宠图标（自动取第一张图片）
```
