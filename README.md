# 键盘计数桌宠 

一个常驻桌面的桌宠，唯一职责是记录你**每天敲击键盘的次数**。

## 功能
- **全局键盘计数**：任你怎么在哪个软件打字都算（仅键盘，鼠标不计）。
- **每天 24:00 刷新**：前一天次数自动归档，新的一天从 0 开始。
- **历史记录**：按天存进 SQLite，可查最近 7 天 / 全部历史（表格展示）。
- **自定义图标**：图片你说了算，随时右键更换。
- **日程表**：点击桌宠弹出独立日程窗口（卡片+勾选+进度条），头顶角标常驻「N 待办」，临近截止半天变红。
- **点击提示**：左键单击弹出「宝宝今天点击键盘的次数是 X，快去休息吧~」。
- **一键最小化**：右键选择后，把当前所有可见窗口全部最小化（不关闭）回到桌面，桌宠仍在原位。
  - 已知限制：Windows 权限隔离（UIPI）下，无法最小化以**管理员身份运行**的窗口（如管理员终端、任务管理器），这些会被静默跳过；其它虚拟桌面上的传统程序也会被一并最小化。
- **开机自启动**：右键菜单里可开/关，开机自动常驻。

## 运行
```bash
# 1. 安装依赖（Python 3.8+）
pip install -r requirements.txt

# 2. 启动
python main.py
```

## 使用
- **拖动**：按住图标拖到任意位置。
- **左键单击**：弹气泡显示今天次数，同时弹出日程窗口（待办列表）。
- **头顶角标**：常驻显示「N 待办」，有任务临近截止半天时变红。
- **右键** → 菜单：
  - 最近 7 天（以表格形式展示近 7 天）
  - 历史所有（以表格形式展示全部历史）
  - 键盘热力图（26 键实时热度）
  - 一键最小化（最小化所有窗口回到桌面，不关闭）
  - 更换图标（上传你自己的图片）
  - 开机自启动（勾选 = 开启）
  - 退出

## 数据
数据库 `keyboard_stats.db`，表 `daily_stats`：
| date | count |
|------|-------|
| 2026-10-12 | 1234 |

按天聚合，一行代表一天。程序每天 00:00 会把当天次数写入该表并开始新 day。

### 待办日程表（todo）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| title | TEXT | 待办标题 |
| due_at | TEXT | 截止时间 'YYYY-MM-DD HH:MM'（排序键） |
| done | INTEGER | 0未完成 / 1已完成 |
| done_at | TEXT | 完成时刻（勾掉留一天用） |
| created_at | TEXT | 创建时间 |

- **勾掉留一天**：完成项当天显示，第二天自动隐藏。
- **没做轮换下一天**：未完成项自然顺延到第二天继续展示。
- **排序**：按截止时间升序（近→远）。
- **汉字展示**：`due_at` 经 `format_due()` 显示为 `2026年10月19日 14时00分`，列表第三列完整日期时间。
- **无优先级、无完成率/近7天统计**。

## 图标
桌宠自动使用 `assets/` 目录下的第一张图片作为图标。想换图：右键桌宠 → 更换图标，或直接替换 `assets/` 里的图片。

## 模块结构
```
main.py          入口（含异常兜底）
autostart.py     开机自启动（启动文件夹 + VBS 静默启动器）
logger.py        运行日志（pet.log）
config.py        配置与路径（find_icon 自动扫描 assets/ 图标）
db.py            SQLite 按天聚合（含近7天 / 全部历史查询）
db_todo.py       SQLite 待办数据层（todo 表）
listener.py      全局键盘监听
tracker.py       线程安全计数 + 跨天滚动
scheduler.py     24:00 刷新 + 每 20s 落库
pet_ui/          界面包（拆分自原单文件）
  ├ app.py         PetApp 主类：窗口/图标/拖拽/菜单
  ├ renderer.py    图像流水线（Pillow）
  ├ animations.py  呼吸/挤压/拎起动画
  ├ popup.py       气泡 + MVP 徽章特效
  ├ heatmap.py     键盘热力图
  ├ schedule.py    日程表（独立窗口 + 头顶角标）
  ├ table.py       历史表格
  ├ minimize.py    一键最小化（EnumWindows + ShowWindowAsync）
  └ theme.py       配色与参数常量
assets/          桌宠图标（自动取第一张图片）
```
完整说明见 `PROJECT_STRUCTURE.md`。
